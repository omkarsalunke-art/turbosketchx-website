# TurboSketchX Website

A complete responsive portfolio + portrait commission website.

## Files
- index.html — website structure
- style.css — design and responsive styling
- script.js — menu, price tabs and WhatsApp order form
- assets/ — your artwork images

## IMPORTANT
Open `script.js` and replace:
    const WHATSAPP_NUMBER = '919999999999';

with your own WhatsApp number in international format, without + or spaces.

Example:
    const WHATSAPP_NUMBER = '919876543210';

## Run locally
You can simply open `index.html` in a browser.

For a local server:
    python -m http.server 8000

Then open:
    http://localhost:8000

## Publish free
You can upload this folder to GitHub Pages, Netlify, or Vercel.
